## À propos

Ce portfolio statique met en avant un parcours de développeur web au travers d'une page unique, d'un mode clair/sombre, d'animations et de sections consacrées aux projets, compétences et expériences.

## Fonctionnalités

- présentation responsive ;
- navigation par ancres ;
- bascule clair/sombre ;
- animations et interactions JavaScript ;
- galerie de projets ;
- ressources graphiques et typographies locales.

## Consulter localement

Aucune dépendance n'est nécessaire. Ouvrir index.html dans un navigateur ou servir le dossier avec un serveur statique :

    python -m http.server 8000

Ouvrir ensuite http://localhost:8000.

## Contexte

Projet frontend conservé comme étape historique de conception d'un portfolio. Une version plus récente de la présentation est désormais disponible sur le profil GitHub.
